pitr-config — short guide

Configuring Point-in-time restore on Windows 11.

What this tool is for

Windows 11 can take full system snapshots and roll the machine back to an earlier state. How often it does that and how long a snapshot is kept can only be set on the Enterprise edition — everywhere else those two dropdowns are greyed out.

This tool sets them anyway. The restriction lives in the Settings user interface, not in the engine underneath, and the engine takes its configuration from a place the tool can write to directly.

A snapshot whenever one is wanted

The green button at the top of the window, Create snapshot now, creates a restore point immediately — no waiting for the schedule, and no setting touched. One click worth spending before a driver installation, an edit to the registry, or a first run of unfamiliar software.

It takes a moment: the task runs, Windows writes the shadow copy, and the new point then appears in the list below. Since the scheduled task otherwise runs only while the machine is idle, the button lifts that condition for this one run and restores it afterwards.

The checkbox underneath, At every system start, does the same thing a few minutes after every boot. Windows already asks for a point at startup, but its request waits for the system to go idle - which a machine that just started is not. Note that with Fast Startup switched on, shutting down and powering on again is a resume rather than a boot, and no boot trigger fires; a restart is a real boot.

And the way back

A restore point is applied from the Windows Recovery Environment, not from inside a running Windows. Restart to recovery, next to the state line, reboots straight into it. Windows does offer that route — Settings → System → Recovery → Advanced startup — but several clicks away from anything to do with restore points.

That same line shows whether the environment is there at all. If it is switched off, no restore point can be applied by anyone, and the line turns red.

Or just one file, not the whole system

Restore points aren’t only for rolling the whole drive back. Right-click any file or folder, open Properties, and the Previous Versions tab lists every restore point that captured it — Open shows the old content without touching anything, Restore brings back only that one item. No recovery environment, no restart: this runs from inside a working Windows, reading the same shadow copies the tool already creates.

Windows has offered this for years, on every edition; what changes with more frequent restore points is how far back the list reaches.

Getting started

Double-click pitr-config.cmd. It asks for administrator rights itself, then opens a window. Nothing is written until a button is pressed. The file can just as well sit on a USB stick or a network share; it runs from wherever it is.

The language follows the Windows display language; the buttons in the top right switch it at any time.

On start the tool asks GitHub whether a newer version exists and shows a line with a link if there is one. It never downloads or installs anything by itself, and a failed check stays silent. Starting it as pitr-config.cmd noupdate skips the check.

The settings

  • Feature enabled — switches Point-in-time restore on or off.
  • Frequency — 1 to 24 hours between restore points.
  • Retention — 1 to 7 days before a point is deleted automatically.
  • Maximum storage — 2 to 50 GB for all restore points together.

Each list starts with Windows default, which removes that single override again. Underneath each list, in grey, stands the value currently in effect and where it comes from.

Five things worth knowing

Frequency is an earliest possible interval, not a promise. Restore points are only created while the system is idle. If the machine is in use, or switched off, the run is postponed and a slot can be skipped entirely. Setting one hour on a machine used all day will not produce twenty-four points. The window shows the task status, so a run that is waiting stays visible. If points stop appearing altogether, Check idle further down says whether an idle state is still being reported at all.

Only the Windows drive is covered. Other partitions and other disks are not included, not even on the same physical disk. Data there is neither protected nor rolled back, and still needs a backup of its own.

This is an unofficial route. The configuration values are not documented by Microsoft. A future Windows release may change them, at which point the normal Windows behaviour simply applies again.

The recovery environment has to be there. A restore point is applied from it, not from inside Windows. The window shows whether it is present; if it is switched off, the points are of no use — an elevated reagentc /enable usually puts it back.

It is not a backup. The points sit on the very drive they protect, so a failed disk, a stolen machine or a wiped volume takes them along. Point-in-time restore answers a bad update or a bad driver; against hardware failure, theft or ransomware only a backup on separate media helps.

When no restore point appears

A run only happens while the system is idle, so one falling due while the machine is in use is dropped — silently, without a line in any log. The window counts those beside the task status as runs skipped.

By themselves they mean nothing; they are the normal case while somebody is working. They become a symptom only when Windows stops reporting an idle state at all. From then on nothing that waits for idle runs any more — snapshots are merely the part you notice.

Once runs have been skipped, a box with Check idle appears. It reads every other scheduled task on this machine that waits for idle — disk cleanup, storage sense and two dozen more — and compares them with the last boot. Has at least one of them run, idle detection works and the machine was simply in use. Has none of them run while the system has been up for hours, the idle state is blocked, usually by a program or a driver holding a power request. An elevated powercfg /requests names it; ending that process, or a restart, releases it.

Undoing everything

Reset everything removes all of it in one step. Existing restore points are never deleted by this tool — it only changes configuration.

Support

The tool is free and stays that way. If it saved an afternoon of reinstalling Windows, a coffee is welcome: paypal.me/teslapunk. Nothing in the tool itself ever asks for money — no notice, no link, no reminder.

pitr-config — Kurzanleitung

Die Zeitpunktwiederherstellung von Windows 11 einstellen.

Wofür das Werkzeug da ist

Windows 11 kann vollständige Systemabbilder anlegen und den Rechner auf einen früheren Stand zurücksetzen. Wie oft das geschieht und wie lange ein Abbild aufgehoben wird, lässt sich nur auf der Enterprise-Edition einstellen — überall sonst sind diese beiden Auswahlfelder ausgegraut.

Dieses Werkzeug setzt sie trotzdem. Die Sperre sitzt allein in der Oberfläche der Einstellungen, nicht in der darunterliegenden Engine, und die Engine liest ihre Konfiguration von einer Stelle, die das Werkzeug direkt beschreiben kann.

Ein Schnappschuss, wann immer er gebraucht wird

Die grüne Schaltfläche oben im Fenster, Schnappschuss jetzt erstellen, legt sofort einen Wiederherstellungspunkt an — ohne auf den Zeitplan zu warten und ohne dass sich an einer Einstellung etwas ändert. Ein Klick, der sich vor einer Treiberinstallation, einem Eingriff in die Registry oder dem ersten Start unbekannter Software lohnt.

Es dauert einen Moment: Die Aufgabe läuft, Windows schreibt die Schattenkopie, danach erscheint der neue Punkt in der Liste darunter. Weil die geplante Aufgabe sonst nur im Leerlauf läuft, hebt die Schaltfläche diese Bedingung für diesen einen Lauf auf und stellt sie danach wieder her.

Das Kontrollkästchen darunter, Bei jedem Systemstart, tut dasselbe wenige Minuten nach jedem Start. Windows fordert beim Start ohnehin einen Punkt an, doch die Anforderung wartet auf den Leerlauf - und der ist bei einem frisch gestarteten Rechner nicht gegeben. Zu beachten: Bei eingeschaltetem Schnellstart ist Herunterfahren und wieder Einschalten kein Start, sondern eine Fortsetzung, und kein Start-Auslöser greift; ein Neustart dagegen schon.

Und der Weg zurück

Ein Wiederherstellungspunkt wird aus der Windows-Wiederherstellungsumgebung heraus angewendet, nicht aus dem laufenden Windows. Neustart zur Wiederherstellung neben der Zustandszeile startet direkt dorthin. Windows bietet diesen Weg durchaus — Einstellungen → System → Wiederherstellung → Erweiterter Start — nur mehrere Klicks entfernt von allem, was mit Wiederherstellungspunkten zu tun hat.

Dieselbe Zeile zeigt, ob es diese Umgebung überhaupt gibt. Ist sie abgeschaltet, kann niemand einen Wiederherstellungspunkt anwenden, und die Zeile wird rot.

Oder nur eine Datei, nicht das ganze System

Wiederherstellungspunkte sind nicht nur da, um das ganze Laufwerk zurückzudrehen. Rechtsklick auf eine beliebige Datei oder einen Ordner, Eigenschaften, und die Registerkarte Vorgängerversionen listet jeden Wiederherstellungspunkt auf, der sie erfasst hat — Öffnen zeigt den alten Inhalt, ohne etwas zu verändern, Wiederherstellen holt nur dieses eine Element zurück. Keine Wiederherstellungsumgebung, kein Neustart: Das läuft aus dem laufenden Windows heraus, mit denselben Schattenkopien, die das Werkzeug ohnehin anlegt.

Windows bietet das seit Jahren, auf jeder Edition; mit häufigeren Wiederherstellungspunkten wächst nur, wie weit die Liste zurückreicht.

Erste Schritte

pitr-config.cmd doppelklicken. Die Datei fordert selbst Administratorrechte an und öffnet ein Fenster. Geschrieben wird erst beim Druck auf eine Schaltfläche. Die Datei kann ebenso gut auf einem USB-Stick oder einer Netzwerkfreigabe liegen; sie läuft von dort, wo sie ist.

Die Sprache richtet sich nach der Windows-Anzeigesprache; die Schaltflächen oben rechts stellen sie jederzeit um.

Beim Start fragt das Werkzeug bei GitHub nach, ob es eine neuere Fassung gibt, und zeigt dann eine Zeile mit Link. Heruntergeladen oder installiert wird nie etwas von allein, und eine fehlgeschlagene Abfrage bleibt stumm. Mit pitr-config.cmd noupdate unterbleibt die Abfrage.

Die Einstellungen

  • Feature aktiv — schaltet die Zeitpunktwiederherstellung ein oder aus.
  • Häufigkeit — 1 bis 24 Stunden Abstand zwischen zwei Punkten.
  • Aufbewahrung — 1 bis 7 Tage, bis ein Punkt automatisch gelöscht wird.
  • Maximaler Speicherplatz — 2 bis 50 GB für alle Punkte zusammen.

Jede Liste beginnt mit Windows-Standard; damit wird genau diese eine Überschreibung wieder entfernt. Unter jeder Liste steht in Grau der aktuell wirksame Wert und woher er stammt.

Fünf Dinge, die man wissen sollte

Die Häufigkeit ist ein frühestmöglicher Abstand, keine Zusage. Wiederherstellungspunkte entstehen nur, wenn das System im Leerlauf ist. Wird der Rechner benutzt oder ist er ausgeschaltet, verschiebt sich der Lauf, und ein Termin kann ganz ausfallen. Wer eine Stunde einstellt und den Rechner den ganzen Tag benutzt, bekommt keine vierundzwanzig Punkte. Das Fenster zeigt den Status der Aufgabe an, damit erkennbar ist, wann ein Lauf wartet. Bleiben Punkte ganz aus, sagt Leerlauf prüfen weiter unten, ob der Leerlauf überhaupt noch gemeldet wird.

Erfasst wird nur das Windows-Laufwerk. Weitere Partitionen und weitere Festplatten sind nicht dabei — auch nicht auf derselben physischen Platte. Daten dort werden weder geschützt noch zurückgesetzt und brauchen weiterhin eine eigene Sicherung.

Das ist ein inoffizieller Weg. Die Konfigurationswerte sind von Microsoft nicht dokumentiert. Eine künftige Windows-Version kann sie ändern; dann gilt wieder das normale Verhalten von Windows.

Die Wiederherstellungsumgebung muss da sein. Ein Wiederherstellungspunkt wird von dort aus angewendet, nicht aus Windows heraus. Das Fenster zeigt, ob sie vorhanden ist; fehlt sie, nützen die Punkte nichts — ein reagentc /enable mit Administratorrechten stellt sie meist wieder her.

Es ist keine Sicherung. Die Punkte liegen auf genau dem Laufwerk, das sie schützen — eine defekte Platte, ein gestohlener Rechner oder ein gelöschtes Laufwerk nimmt sie mit. Die Zeitpunktwiederherstellung ist die Antwort auf ein missglücktes Update oder einen fehlerhaften Treiber; gegen Hardwaredefekt, Diebstahl oder Verschlüsselungstrojaner hilft nur eine Sicherung auf getrenntem Datenträger.

Wenn gar kein Punkt mehr entsteht

Ein Lauf findet nur im Leerlauf statt. Wird er fällig, während der Rechner benutzt wird, fällt er aus — stillschweigend, ohne eine Zeile in irgendeinem Protokoll. Das Fenster zählt diese Fälle neben dem Aufgabenstatus als ausgefallene Läufe.

Für sich genommen sagen sie nichts; sie sind der Normalfall, solange jemand am Rechner sitzt. Zum Symptom werden sie erst, wenn Windows überhaupt keinen Leerlauf mehr meldet. Dann läuft nichts mehr, was auf Leerlauf wartet — die Schnappschüsse sind nur das, was zuerst auffällt.

Sobald Läufe ausgefallen sind, erscheint ein Kasten mit Leerlauf prüfen. Er liest jede andere geplante Aufgabe dieses Rechners, die auf Leerlauf wartet — Datenträgerbereinigung, Speicheroptimierung und zwei Dutzend weitere — und vergleicht sie mit dem letzten Systemstart. Ist wenigstens eine gelaufen, arbeitet die Leerlauferkennung, und der Rechner war nur in Benutzung. Ist keine gelaufen, während das System seit Stunden läuft, ist der Leerlauf blockiert, meist durch ein Programm oder einen Treiber, der eine Energieanforderung hält. powercfg /requests mit Rechten nennt ihn; das Beenden dieses Prozesses oder ein Neustart gibt ihn frei.

Alles rückgängig machen

Alles zurücksetzen entfernt sämtliche Werte in einem Schritt. Vorhandene Wiederherstellungspunkte löscht das Werkzeug nie — es ändert ausschließlich die Konfiguration.

Unterstützung

Das Werkzeug ist kostenlos und bleibt es. Wenn es einen Nachmittag Windows-Neuinstallation erspart hat, ist ein Kaffee willkommen: paypal.me/teslapunk. Im Werkzeug selbst wird nie nach Geld gefragt — kein Hinweis, kein Link, keine Erinnerung.

pitr-config — korte handleiding

Point-in-time restore op Windows 11 instellen.

Waar dit hulpprogramma voor dient

Windows 11 kan volledige systeemmomentopnamen maken en de computer terugzetten naar een eerdere staat. Hoe vaak dat gebeurt en hoe lang een momentopname bewaard blijft, is alleen instelbaar op de Enterprise-editie — overal elders staan die twee keuzelijsten grijs.

Dit hulpprogramma stelt ze toch in. De beperking zit alleen in de gebruikersinterface van Instellingen, niet in de onderliggende engine, en die engine haalt zijn configuratie uit een plek waar het hulpprogramma rechtstreeks naartoe kan schrijven.

Een momentopname wanneer die nodig is

De groene knop bovenaan het venster, Nu momentopname maken, maakt direct een herstelpunt aan — zonder te wachten op het schema en zonder dat er een instelling verandert. Eén klik die de moeite waard is vóór een stuurprogramma-installatie, een ingreep in het register, of de eerste keer dat onbekende software wordt gestart.

Het duurt even: de taak draait, Windows schrijft de schaduwkopie, en het nieuwe punt verschijnt daarna in de lijst eronder. Omdat de geplande taak verder alleen draait terwijl de computer inactief is, heft de knop die voorwaarde voor deze ene keer op en herstelt hem daarna.

Het selectievakje eronder, Bij elke systeemstart, doet hetzelfde enkele minuten na elke start. Windows vraagt bij het opstarten sowieso om een punt, maar dat verzoek wacht tot het systeem inactief is - en dat is een net gestarte computer niet. Let op: bij ingeschakelde snelle start is afsluiten en weer inschakelen een hervatting, geen start, en gaat er geen opstarttrigger af; een herstart daarentegen wel.

En de weg terug

Een herstelpunt wordt toegepast vanuit de Windows-herstelomgeving, niet vanuit een lopend Windows. Opnieuw opstarten naar herstel, naast de statusregel, start daar direct naartoe. Windows biedt die route ook zelf — Instellingen → Systeem → Herstel → Geavanceerd opstarten — maar wel meerdere klikken verwijderd van alles wat met herstelpunten te maken heeft.

Diezelfde regel laat zien of die omgeving er überhaupt is. Is ze uitgeschakeld, dan kan niemand een herstelpunt toepassen, en de regel wordt rood.

Of gewoon één bestand, niet het hele systeem

Herstelpunten zijn niet alleen bedoeld om de hele schijf terug te draaien. Rechtsklik op een willekeurig bestand of map, open Eigenschappen, en het tabblad Vorige versies toont elk herstelpunt dat het heeft vastgelegd — Openen toont de oude inhoud zonder iets te wijzigen, Herstellen brengt alleen dat ene item terug. Geen herstelomgeving, geen herstart: dit werkt vanuit een werkend Windows, met dezelfde schaduwkopieën die het hulpprogramma toch al aanmaakt.

Windows biedt dit al jaren, op elke editie; wat verandert met frequentere herstelpunten is alleen hoe ver de lijst terugreikt.

Aan de slag

Dubbelklik op pitr-config.cmd. Het bestand vraagt zelf om beheerdersrechten en opent daarna een venster. Er wordt pas iets geschreven na het indrukken van een knop. Het bestand mag net zo goed op een USB-stick of een netwerklocatie staan; het draait vanaf waar het staat.

De taal volgt de Windows-weergavetaal; de knoppen rechtsboven schakelen op elk moment om.

Bij het starten vraagt het hulpprogramma aan GitHub of er een nieuwere versie is en toont dan een regel met een link als dat zo is. Er wordt nooit iets vanzelf gedownload of geïnstalleerd, en een mislukte controle blijft stil. Starten als pitr-config.cmd noupdate slaat de controle over.

  • Functie ingeschakeld — schakelt Point-in-time restore aan of uit.
  • Frequentie — 1 tot 24 uur tussen herstelpunten.
  • Bewaartermijn — 1 tot 7 dagen voordat een punt automatisch wordt verwijderd.
  • Maximale opslag — 2 tot 50 GB voor alle herstelpunten samen.

Elke lijst begint met Windows-standaard, wat precies die ene overschrijving weer opheft. Onder elke lijst staat in grijs de waarde die nu geldt en waar die vandaan komt.

Vijf dingen die de moeite waard zijn om te weten

Frequentie is een vroegst mogelijke interval, geen belofte. Herstelpunten ontstaan alleen terwijl het systeem inactief is. Is de computer in gebruik of uitgeschakeld, dan wordt de uitvoering uitgesteld en kan een beurt helemaal vervallen. Wie één uur instelt op een computer die de hele dag wordt gebruikt, krijgt geen vierentwintig punten. Het venster toont de status van de taak, zodat een wachtende uitvoering zichtbaar blijft. Blijven punten helemaal uit, dan zegt Inactiviteit controleren verderop of er nog wel een inactieve status wordt gemeld.

Alleen het Windows-station wordt gedekt. Andere partities en andere schijven zijn niet inbegrepen, ook niet op dezelfde fysieke schijf. Gegevens daar worden noch beschermd noch teruggezet, en hebben nog steeds een eigen back-up nodig.

Dit is een niet-officiële route. De configuratiewaarden zijn niet door Microsoft gedocumenteerd. Een toekomstige Windows-versie kan ze wijzigen; daarna geldt gewoon weer het normale gedrag van Windows.

De herstelomgeving moet aanwezig zijn. Een herstelpunt wordt vandaaruit toegepast, niet vanuit Windows zelf. Het venster toont of ze aanwezig is; ontbreekt ze, dan hebben de punten geen nut — een verhoogd reagentc /enable herstelt haar meestal.

Dit is geen back-up. De punten staan op precies de schijf die ze beschermen — een defecte schijf, een gestolen computer of een gewist volume neemt ze mee. Point-in-time restore is het antwoord op een mislukte update of een slecht stuurprogramma; tegen hardwarestoring, diefstal of ransomware helpt alleen een back-up op afzonderlijke media.

Als er helemaal geen herstelpunt meer verschijnt

Een uitvoering vindt alleen plaats terwijl het systeem inactief is, dus eentje die vervalt terwijl de computer in gebruik is, wordt genegeerd — stilzwijgend, zonder regel in enig logboek. Het venster telt die gevallen naast de taakstatus als overgeslagen uitvoeringen.

Op zichzelf betekenen ze niets; ze zijn de normale gang van zaken zolang iemand aan het werk is. Ze worden pas een symptoom als Windows helemaal geen inactieve status meer meldt. Vanaf dat moment draait niets meer dat op inactiviteit wacht — momentopnamen zijn slechts wat het eerst opvalt.

Zodra uitvoeringen zijn overgeslagen, verschijnt een vak met Inactiviteit controleren. Het leest elke andere geplande taak op deze computer die op inactiviteit wacht — schijfopruiming, opslagverkenner en nog twee dozijn andere — en vergelijkt ze met de laatste systeemstart. Is er minstens één uitgevoerd, dan werkt de inactiviteitsdetectie en was de computer gewoon in gebruik. Is er geen enkele uitgevoerd terwijl het systeem al uren draait, dan is de inactiviteit geblokkeerd, meestal door een programma of stuurprogramma dat een energieaanvraag vasthoudt. Een verhoogd powercfg /requests noemt het; dat proces beëindigen, of een herstart, maakt het weer vrij.

Alles ongedaan maken

Alles resetten verwijdert alles in één stap. Bestaande herstelpunten worden door dit hulpprogramma nooit verwijderd — het wijzigt uitsluitend de configuratie.

Ondersteuning

Het hulpprogramma is gratis en blijft dat. Als het een middag Windows opnieuw installeren heeft bespaard, is een kopje koffie welkom: paypal.me/teslapunk. In het hulpprogramma zelf wordt nooit om geld gevraagd — geen melding, geen link, geen herinnering.

pitr-config — guide rapide

Configurer Point-in-time restore sous Windows 11.

À quoi sert cet outil

Windows 11 peut créer des instantanés complets du système et ramener la machine à un état antérieur. La fréquence à laquelle il le fait et la durée de conservation d'un instantané ne peuvent être réglées que sur l'édition Enterprise : ailleurs, ces deux listes sont grisées.

Cet outil les règle malgré tout. La restriction se trouve uniquement dans l'interface des Paramètres, pas dans le moteur sous-jacent, et ce moteur lit sa configuration à un endroit où l'outil peut écrire directement.

Un instantané dès qu'on en a besoin

Le bouton vert en haut de la fenêtre, Créer un instantané maintenant, crée immédiatement un point de restauration — sans attendre la planification et sans toucher au moindre réglage. Un clic qui vaut la peine avant l'installation d'un pilote, une intervention dans le registre ou le premier lancement d'un logiciel inconnu.

Cela prend un moment : la tâche s'exécute, Windows écrit le cliché instantané, puis le nouveau point apparaît dans la liste en dessous. Comme la tâche planifiée ne s'exécute autrement que pendant l'inactivité, le bouton lève cette condition pour cette seule exécution et la rétablit ensuite.

La case à cocher en dessous, À chaque démarrage du système, fait la même chose quelques minutes après chaque démarrage. Windows demande déjà un point au démarrage, mais sa demande attend l'inactivité du système - qu'une machine qui vient de démarrer n'a pas. À noter : avec le démarrage rapide activé, arrêter puis rallumer est une reprise et non un démarrage, et aucun déclencheur ne se produit ; un redémarrage, lui, en est un.

Et le chemin du retour

Un point de restauration s'applique depuis l'environnement de récupération de Windows, pas depuis un Windows en cours d'exécution. Redémarrer vers la récupération, à côté de la ligne d'état, redémarre directement dedans. Windows propose bien ce chemin — Paramètres → Système → Récupération → Démarrage avancé — mais à plusieurs clics de tout ce qui touche aux points de restauration.

Cette même ligne indique si cet environnement existe. S'il est désactivé, personne ne peut appliquer de point de restauration, et la ligne passe au rouge.

Ou juste un fichier, pas tout le système

Les points de restauration ne servent pas qu’à revenir en arrière sur tout le disque. Clic droit sur un fichier ou un dossier, Propriétés, et l’onglet Versions précédentes répertorie chaque point de restauration qui l’a capturé — Ouvrir montre l’ancien contenu sans rien modifier, Restaurer ne ramène que cet élément.   • Frequenza — da 1 a 24 ore tra un punto di ripristino e l'altro.
  • Conservazione — da 1 a 7 giorni prima che un punto venga eliminato automaticamente.
  • Spazio massimo — da 2 a 50 GB per tutti i punti di ripristino insieme.

Ogni elenco inizia con Impostazione predefinita di Windows, che rimuove di nuovo quella singola modifica. Sotto ogni elenco, in grigio, è indicato il valore attualmente in vigore e da dove proviene.

Cinque cose da sapere

La frequenza è un intervallo minimo, non una promessa. I punti di ripristino vengono creati solo mentre il sistema è inattivo. Se il computer è in uso, o spento, l'esecuzione viene rinviata e un appuntamento può saltare del tutto. Impostare un'ora su un computer usato tutto il giorno non produrrà ventiquattro punti. La finestra mostra lo stato dell'attività, così un'esecuzione in attesa resta visibile. Se i punti smettono del tutto di comparire, Verifica inattività più in basso dice se un'inattività viene ancora segnalata.

Viene protetta solo l'unità di Windows. Le altre partizioni e gli altri dischi non sono inclusi, nemmeno sullo stesso disco fisico. I dati che vi si trovano non sono né protetti né ripristinati e hanno ancora bisogno di un backup proprio.

È una via non ufficiale. I valori di configurazione non sono documentati da Microsoft. Una futura versione di Windows può cambiarli, e in quel caso torna semplicemente il comportamento normale di Windows.

L'ambiente di ripristino deve esserci. Un punto di ripristino viene applicato da lì, non da dentro Windows. La finestra mostra se è presente; se è disattivato, i punti non servono a nulla: un reagentc /enable con diritti di amministratore di solito lo ristabilisce.

Non è un backup. I punti si trovano sull'unità stessa che proteggono: un disco guasto, un computer rubato o un volume cancellato se li porta via. Il ripristino a un punto nel tempo risponde a un aggiornamento mal riuscito o a un driver difettoso; contro un guasto hardware, un furto o un ransomware serve solo un backup su un supporto separato.

Quando non compare più alcun punto

Un'esecuzione avviene solo durante l'inattività. Quella che scade mentre il computer è in uso viene scartata — in silenzio, senza una riga in alcun registro. La finestra le conta accanto allo stato dell'attività come esecuzioni saltate.

Di per sé non significano nulla: sono la norma finché qualcuno lavora. Diventano un sintomo solo quando Windows smette del tutto di segnalare inattività. Allora non viene più eseguito nulla che la attenda — gli snapshot sono solo la parte che si nota.

Appena vengono saltate delle esecuzioni compare un riquadro con Verifica inattività. Legge tutte le altre attività pianificate della macchina che attendono l'inattività — pulizia disco, sensore memoria e altre due dozzine — e le confronta con l'ultimo avvio. Se almeno una è stata eseguita, il rilevamento funziona e il computer era semplicemente in uso. Se non ne è stata eseguita nessuna mentre il sistema è acceso da ore, l'inattività è bloccata, di solito da un programma o un driver che mantiene una richiesta di alimentazione. powercfg /requests con privilegi lo indica; terminare quel processo, o riavviare, la libera.

Annullare tutto

Reimposta tutto rimuove ogni cosa in un solo passaggio. I punti di ripristino esistenti non vengono mai eliminati dallo strumento: cambia soltanto la configurazione.

Konfigurowanie przywracania do punktu w czasie w systemie Windows 11.

Do czego służy to narzędzie

Windows 11 potrafi tworzyć pełne migawki systemu i cofać komputer do wcześniejszego stanu. To, jak często to robi i jak długo migawka jest przechowywana, można ustawić wyłącznie w edycji Enterprise — wszędzie indziej te dwie listy są wyszarzone.

To narzędzie ustawia je mimo to. Ograniczenie tkwi w interfejsie aplikacji Ustawienia, a nie w mechanizmie pod spodem, a ten mechanizm czyta swoją konfigurację z miejsca, do którego narzędzie może pisać bezpośrednio.

Migawka wtedy, kiedy jest potrzebna

Zielony przycisk u góry okna, Utwórz migawkę teraz, tworzy punkt przywracania natychmiast — bez czekania na harmonogram i bez zmiany jakiegokolwiek ustawienia. Jedno kliknięcie warte zachodu przed instalacją sterownika, zmianą w rejestrze albo pierwszym uruchomieniem nieznanego programu.

Trwa to chwilę: zadanie jest wykonywane, Windows zapisuje kopię w tle, a nowy punkt pojawia się na liście poniżej. Ponieważ zaplanowane zadanie poza tym uruchamia się tylko przy bezczynnym systemie, przycisk znosi ten warunek na to jedno uruchomienie i przywraca go zaraz potem.

Pole wyboru poniżej, Przy każdym uruchomieniu systemu, robi to samo kilka minut po każdym starcie. Windows i tak prosi o punkt przy starcie, ale to żądanie czeka na bezczynność systemu - której dopiero co uruchomiony komputer nie ma. Warto wiedzieć: przy włączonym szybkim uruchamianiu wyłączenie i ponowne włączenie to wznowienie, a nie start, i żaden wyzwalacz startu nie zadziała; ponowne uruchomienie to prawdziwy start.

I droga powrotna

Punkt przywracania stosuje się ze środowiska odzyskiwania systemu Windows, a nie z poziomu działającego systemu. Uruchom ponownie do odzyskiwania obok wiersza stanu uruchamia komputer prosto do niego. Windows udostępnia tę drogę — Ustawienia → System → Odzyskiwanie → Uruchamianie zaawansowane — ale kilka kliknięć od wszystkiego, co dotyczy punktów przywracania.

Ten sam wiersz pokazuje, czy to środowisko w ogóle istnieje. Gdy jest wyłączone, nikt nie może zastosować punktu przywracania, a wiersz staje się czerwony.

Albo tylko jeden plik, nie cały system

Punkty przywracania nie są tylko do cofania całego dysku. Klik prawym przyciskiem na dowolny plik lub folder, Właściwości, a karta Poprzednie wersje wypisuje każdy punkt przywracania, który go uchwycił — Otwórz pokazuje starą zawartość bez niczego zmieniając, Przywróć przywraca tylko ten jeden element. Żadnego środowiska odzyskiwania, żadnego ponownego uruchamiania — działa z poziomu działającego Windows, czytając te same kopie w tle, które narzędzie już tworzy.

Windows oferuje to od lat, na każdej edycji; wraz z częstszymi punktami przywracania zmienia się tylko to, jak daleko wstecz sięga lista.

Pierwsze kroki

Podwójne kliknięcie pliku pitr-config.cmd. Plik sam prosi o uprawnienia administratora i otwiera okno. Nic nie zostaje zapisane, dopóki nie zostanie naciśnięty przycisk. Plik może równie dobrze leżeć na pendrivie albo w udziale sieciowym — działa stamtąd, gdzie jest.

Język odpowiada językowi wyświetlania systemu Windows; przyciski w prawym górnym rogu przełączają go w dowolnej chwili.

Przy starcie narzędzie pyta serwis GitHub, czy istnieje nowsza wersja, i pokazuje wiersz z odnośnikiem, jeśli tak jest. Nigdy niczego nie pobiera ani nie instaluje samo, a nieudane sprawdzenie pozostaje bez komunikatu. Uruchomienie jako pitr-config.cmd noupdate pomija sprawdzenie.

Ustawienia

  • Funkcja włączona — włącza lub wyłącza przywracanie do punktu w czasie.
  • Częstotliwość — od 1 do 24 godzin między punktami przywracania.
  • Czas przechowywania — od 1 do 7 dni, zanim punkt zostanie usunięty automatycznie.
  • Maksymalne miejsce — od 2 do 50 GB łącznie dla wszystkich punktów.

Każda lista zaczyna się od pozycji Ustawienie domyślne systemu Windows, która usuwa tę jedną zmianę. Pod każdą listą, na szaro, widać wartość obecnie obowiązującą i to, skąd pochodzi.

Pięć rzeczy wartych uwagi

Częstotliwość to najmniejszy możliwy odstęp, nie obietnica. Punkty przywracania powstają tylko wtedy, gdy system jest bezczynny. Gdy komputer jest używany albo wyłączony, uruchomienie zostaje przesunięte, a termin może zostać pominięty w całości. Ustawienie jednej godziny na komputerze używanym przez cały dzień nie da dwudziestu czterech punktów. Okno pokazuje stan zadania, więc oczekujące uruchomienie pozostaje widoczne. Jeśli punkty przestaną się pojawiać całkowicie, Sprawdź bezczynność niżej powie, czy bezczynność jest jeszcze zgłaszana.

Obejmowany jest tylko dysk systemu Windows. Pozostałe partycje i inne dyski nie są uwzględniane, nawet na tym samym dysku fizycznym. Dane na nich nie są ani chronione, ani przywracane i nadal wymagają własnej kopii zapasowej.

To droga nieoficjalna. Wartości konfiguracyjne nie są udokumentowane przez firmę Microsoft. Przyszła wersja systemu Windows może je zmienić — wtedy po prostu wraca zwykłe zachowanie systemu.

Środowisko odzyskiwania musi istnieć. Punkt przywracania stosuje się właśnie z niego, a nie z poziomu systemu Windows. Okno pokazuje, czy jest dostępne; gdy jest wyłączone, punkty nic nie dają — polecenie reagentc /enable z uprawnieniami administratora zwykle je przywraca.

To nie jest kopia zapasowa. Punkty znajdują się na tym samym dysku, który chronią — uszkodzony dysk, skradziony komputer albo wymazany wolumin zabiera je ze sobą. Przywracanie do punktu w czasie jest odpowiedzią na nieudaną aktualizację lub wadliwy sterownik; przeciw awarii sprzętu, kradzieży czy ransomware pomaga wyłącznie kopia zapasowa na osobnym nośniku.

Gdy nie pojawia się już żaden punkt

Uruchomienie następuje tylko w czasie bezczynności. To, które wypada, gdy komputer jest używany, zostaje pominięte — po cichu, bez wiersza w jakimkolwiek dzienniku. Okno liczy je obok stanu zadania jako pominięte uruchomienia.

Same w sobie nic nie znaczą: to normalne, dopóki ktoś pracuje. Stają się objawem dopiero wtedy, gdy Windows w ogóle przestaje zgłaszać bezczynność. Wtedy nie uruchamia się już nic, co na nią czeka — migawki są tylko tym, co rzuca się w oczy.

Gdy tylko jakieś uruchomienia zostaną pominięte, pojawia się ramka z przyciskiem Sprawdź bezczynność. Odczytuje wszystkie pozostałe zadania zaplanowane na tym komputerze, które czekają na bezczynność — oczyszczanie dysku, czujnik pamięci i dwa tuziny innych — i porównuje je z ostatnim uruchomieniem systemu. Jeśli choć jedno się wykonało, wykrywanie działa, a komputer był po prostu używany. Jeśli żadne się nie wykonało, a system działa od godzin, bezczynność jest zablokowana, zwykle przez program lub sterownik utrzymujący żądanie zasilania. powercfg /requests z uprawnieniami wskaże, który; zakończenie tego procesu albo restart je zwalnia.

Cofnięcie wszystkiego

Resetuj wszystko usuwa całość w jednym kroku. Istniejące punkty przywracania nigdy nie są usuwane przez narzędzie — zmienia ono wyłącznie konfigurację.

Налаштування Point-in-time restore у Windows 11.

Для чого цей інструмент

Windows 11 уміє створювати повні знімки системи й повертати комп'ютер до попереднього стану. Наскільки часто це відбувається і як довго зберігається знімок, можна налаштувати лише в редакції Enterprise — усюди інде обидва ці спадні списки затемнені.

Цей інструмент налаштовує їх попри це. Обмеження сидить лише в інтерфейсі застосунку "Параметри", а не в самому рушії, а рушій читає свою конфігурацію з місця, куди інструмент може писати напряму.

Знімок тоді, коли він потрібен

Зелена кнопка вгорі вікна, Створити знімок зараз, одразу створює точку відновлення — без очікування на розклад і без зміни жодного налаштування. Один клік, який варто витратити перед встановленням драйвера, втручанням у реєстр або першим запуском незнайомого програмного забезпечення.

Це триває якийсь час: завдання виконується, Windows записує тіньову копію, і нова точка з'являється в списку нижче. Оскільки заплановане завдання інакше виконується лише в стані бездіяльності, кнопка знімає цю умову на цей один запуск і потім відновлює її.

Прапорець під ним, При кожному запуску системи, робить те саме через кілька хвилин після кожного старту. Windows і так запитує точку під час запуску, але цей запит чекає на бездіяльність системи - а щойно запущений комп'ютер її не має. Варто знати: за увімкненого швидкого запуску вимкнення й повторне ввімкнення - це відновлення роботи, а не запуск, і жоден тригер запуску не спрацьовує; перезавантаження ж - справжній запуск.

І шлях назад

Точку відновлення застосовують із середовища відновлення Windows, а не зсередини робочого Windows. Перезавантажити у відновлення, поруч із рядком стану, перезавантажує комп'ютер прямо туди. Windows пропонує цей шлях і сам — Параметри → Система → Відновлення → Додаткові варіанти запуску — але це кілька кліків від усього, що стосується точок відновлення.

Той самий рядок показує, чи існує це середовище взагалі. Якщо його вимкнено, ніхто не може застосувати точку відновлення, і рядок стає червоним.

Або лише один файл, а не вся система

Точки відновлення потрібні не лише для відкату всього диска. Клацни правою кнопкою на будь-якому файлі чи папці, відкрий Властивості, і вкладка Попередні версії перелічить кожну точку відновлення, що зафіксувала його — Відкрити показує старий вміст, нічого не змінюючи, Відновити повертає лише цей один елемент. Жодного середовища відновлення, жодного перезавантаження: це працює зсередини робочого Windows, використовуючи ті самі тіньові копії, які інструмент і так створює.

Windows пропонує це роками, у кожній редакції; з частішими точками відновлення змінюється лише те, як далеко в минуле сягає список.

Початок роботи

Двічі клацни pitr-config.cmd. Файл сам запитує права адміністратора, а потім відкриває вікно. Нічого не записується, доки не натиснуто кнопку. Файл цілком може лежати на USB-накопичувачі або мережевому ресурсі - він виконується звідти, де є.

Частота - це найшвидший можливий інтервал, а не обіцянка. Точки відновлення виникають лише поки система бездіяльна. Якщо точки взагалі перестають з'являтися, Перевірити бездіяльність нижче підкаже, чи бездіяльність узагалі ще повідомляється.

Охоплюється лише диск Windows. Інші розділи та інші диски не враховуються, навіть на тому самому фізичному диску. Дані там не захищені й не відновлюються та все одно потребують власної резервної копії.

Це неофіційний шлях. Значення конфігурації не задокументовані Microsoft. Майбутня версія Windows може їх змінити; тоді просто знову діє звичайна поведінка Windows.

Середовище відновлення має існувати. Точку відновлення застосовують саме з нього, а не зсередини Windows. Вікно показує, чи воно є; якщо його вимкнено, точки марні — reagentc /enable з підвищеними правами зазвичай його повертає.

Це не резервна копія. Точки лежать саме на тому диску, який захищають — несправний диск, викрадений комп'ютер або стертий том забирає їх із собою. Point-in-time restore - це відповідь на невдале оновлення чи поганий драйвер; проти апаратної несправності, крадіжки чи програми-вимагача допомагає лише резервна копія на окремому носії.

Коли жодна точка відновлення більше не з'являється

Запуск відбувається лише в стані бездіяльності, тож той, що припадає на момент використання комп'ютера, відкидається — мовчки, без жодного рядка в будь-якому журналі. Вікно рахує ці випадки поряд зі станом завдання як пропущені запуски.

Самі по собі вони нічого не означають; це звичайна справа, поки хтось працює за комп'ютером. Вони стають симптомом лише тоді, коли Windows узагалі перестає повідомляти про бездіяльність. Відтоді не виконується вже ніщо, що чекає на бездіяльність — знімки - лише те, що впадає в очі першим.

Щойно якісь запуски пропущено, з'являється рамка з кнопкою Перевірити бездіяльність. Вона зчитує кожне інше заплановане завдання на цьому комп'ютері, що чекає на бездіяльність — очищення диска, аналізатор сховища й ще два десятки інших — і порівнює їх з останнім запуском системи. Якщо хоч одне виконалося, виявлення бездіяльності працює, а комп'ютер був просто у використанні. Якщо жодне не виконалося, а система працює вже годинами, бездіяльність заблоковано - зазвичай якоюсь програмою чи драйвером, що утримує запит живлення. Команда powercfg /requests із підвищеними правами назве його; завершення цього процесу або перезавантаження звільняє його.

Скасування всього

Скинути все видаляє все за один крок. Наявні точки відновлення цей інструмент ніколи не видаляє — він змінює виключно конфігурацію.

K čemu tento nástroj slouží

Windows 11 umí vytvářet úplné snímky systému a vrátit počítač do dřívějšího stavu. Jak často se to děje a jak dlouho se snímek uchovává, lze nastavit jen v edici Enterprise — všude jinde jsou tyto dvě rozbalovací nabídky zašedlé.

Tento nástroj je nastaví přesto. Omezení sedí jen v uživatelském rozhraní Nastavení, ne v samotném mechanismu, a ten mechanismus čte svou konfiguraci z místa, kam nástroj může zapisovat přímo.

Snímek, kdykoli je potřeba

Zelené tlačítko nahoře v okně, Vytvořit snímek nyní, vytvoří bod obnovení okamžitě — bez čekání na plán a beze změny jakéhokoli nastavení. Jedno kliknutí, které stojí za to před instalací ovladače, zásahem do registru nebo prvním spuštěním neznámého softwaru.

Chvíli to trvá: úloha proběhne, Windows zapíše stínovou kopii a nový bod se poté objeví v seznamu níže. Protože naplánovaná úloha jinak běží jen při nečinnosti systému, tlačítko tuto podmínku pro tento jeden běh zruší a poté ji obnoví.

Zaškrtávací políčko pod tím, Při každém spuštění systému, dělá totéž pár minut po každém startu. Windows si o bod žádá při startu i tak, ale tento požadavek čeká na nečinnost systému - a tu právě spuštěný počítač nemá. Stojí za povšimnutí: při zapnutém rychlém spuštění je vypnutí a opětovné zapnutí obnovením, ne startem, a žádný spouštěcí trigger se nespustí; restart naopak ano.

A cesta zpět

Bod obnovení se použije z prostředí pro obnovení Windows, ne z běžícího Windows. Restartovat do obnovení, vedle řádku se stavem, restartuje počítač přímo tam. Windows tuto cestu sám nabízí — Nastavení → Systém → Obnovení → Pokročilé spuštění — ale je to několik kliknutí od čehokoli, co s body obnovení souvisí.

Tentýž řádek ukazuje, zda toto prostředí vůbec existuje. Je-li vypnuté, nikdo nemůže bod obnovení použít a řádek zčervená.

Nebo jen jeden soubor, ne celý systém

Body obnovení neslouží jen k vrácení celého disku zpět. Klikni pravým tlačítkem na libovolný soubor nebo složku, otevři Vlastnosti, a karta Předchozí verze vypíše každý bod obnovení, který jej zachytil — Otevřít zobrazí starý obsah, aniž by se cokoli změnilo, Obnovit vrátí zpět jen tuto jednu položku. Žádné prostředí pro obnovení, žádný restart: toto běží uvnitř funkčního Windows, se stejnými stínovými kopiemi, které nástroj stejně vytváří.

Windows tohle nabízí už léta, v každé edici; s častějšími body obnovení se mění jen to, jak daleko do minulosti seznam sahá.

Začínáme

Dvakrát klikni na pitr-config.cmd. Soubor si sám vyžádá práva správce a poté otevře okno. Nic se nezapíše, dokud není stisknuto tlačítko. Soubor může stejně dobře ležet na USB disku nebo síťovém sdílení; běží odtud, kde je.

Jazyk se řídí zobrazovacím jazykem Windows; tlačítka vpravo nahoře jej kdykoli přepnou.

Při spuštění se nástroj zeptá GitHubu, zda existuje novější verze, a pokud ano, zobrazí řádek s odkazem. Nikdy nic samo nestahuje ani neinstaluje a neúspěšná kontrola zůstává tichá. Spuštění jako pitr-config.cmd noupdate kontrolu přeskočí.

Nastavení

  • Funkce zapnuta — zapíná nebo vypíná Point-in-time restore.
  • Frekvence — 1 až 24 hodin mezi body obnovení.
  • Doba uchování — 1 až 7 dní, než je bod automaticky smazán.
  • Maximální úložiště — 2 až 50 GB pro všechny body obnovení dohromady.

Každý seznam začíná položkou Výchozí hodnota Windows, která zruší přesně toto jedno přepsání. Pod každým seznamem stojí šedě hodnota, která je aktuálně platná, a odkud pochází.

Pět věcí, které stojí za vědění

Frekvence je nejdřívější možný interval, ne slib. Body obnovení vznikají jen tehdy, když je systém nečinný. Pokud se počítač používá nebo je vypnutý, spuštění se odloží a termín může zcela propadnout. Kdo nastaví jednu hodinu na počítači používaném celý den, nezíská dvacet čtyři body. Okno zobrazuje stav úlohy, takže čekající běh zůstává viditelný. Pokud body přestanou se objevovat úplně, Zkontrolovat nečinnost níže řekne, zda je nečinnost ještě vůbec hlášena.

Pokrytý je jen disk Windows. Ostatní oddíly a další disky nejsou zahrnuty, ani na stejném fyzickém disku. Data tam nejsou ani chráněna, ani vracena zpět a stále potřebují vlastní zálohu.

Toto je neoficiální cesta. Konfigurační hodnoty nejsou dokumentované společností Microsoft. Budoucí verze Windows je může změnit; pak platí prostě znovu obvyklé chování Windows.

Prostředí pro obnovení musí existovat. Bod obnovení se používá právě z něj, ne z Windows. Okno ukazuje, zda je přítomné; pokud chybí, body nejsou k ničemu — reagentc /enable se zvýšenými oprávněními jej obvykle obnoví.

Toto není záloha. Body leží přesně na disku, který chrání — vadný disk, ukradený počítač nebo smazaný svazek je vezme s sebou. Point-in-time restore je odpovědí na nepovedenou aktualizaci nebo vadný ovladač; proti selhání hardwaru, krádeži nebo ransomwaru pomůže jen záloha na odděleném médiu.

Když se už neobjeví žádný bod obnovení

Ke spuštění dochází jen při nečinnosti systému, takže to, které připadne na chvíli, kdy se počítač používá, se zahodí — potichu, bez řádku v jakémkoli protokolu. Okno je počítá vedle stavu úlohy jako vynechaná spuštění.

Samy o sobě nic neznamenají; jsou běžným případem, dokud někdo pracuje. Stanou se příznakem teprve tehdy, když Windows přestane nečinnost hlásit úplně. Od té chvíle neběží nic, co čeká na nečinnost — snímky jsou jen to, čeho si člověk všimne jako první.

Jakmile jsou nějaká spuštění vynechána, objeví se rámeček s tlačítkem Zkontrolovat nečinnost. Přečte každou jinou naplánovanou úlohu na tomto počítači, která čeká na nečinnost — vyčištění disku, sledování úložiště a dva tucty dalších — a porovná je s posledním spuštěním systému. Proběhla-li alespoň jedna, detekce nečinnosti funguje a počítač byl prostě používán. Neproběhla-li žádná, zatímco systém běží už hodiny, nečinnost je zablokovaná, obvykle nějakým programem nebo ovladačem, který drží požadavek na napájení. Příkaz powercfg /requests se zvýšenými oprávněními jej pojmenuje; ukončení tohoto procesu, nebo restart, jej uvolní.
